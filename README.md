> [!TIP]
> 英华限制性暴力模式指的是如果你学校英华平台的课程视屏没有前置视屏观看限制那么就可以开，这个前置视屏观看限制指的是，一个章节的视屏你要观看必须要先把前面章节的视屏看完才能看，这就叫做前置视屏观看限制。重庆工程学院CQIE可以做到真正意义上的秒刷，使用暴力模式即可。码上研训也可以秒，默认普通模式即为秒。
